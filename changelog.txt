Version: 1.3.7
  Features:
    - Option for inserters to be made in the electromagnetic plant (Configurable, default false)
    - Added a system for automatically finding and assigning recipes to machines as necessary. Currently supports assemblers and chemical plants, and if you aren't using any mods that add these (or are only also using AoP) you can turn this setting off as it might marginally improve startup times.
    - Also added recipe references for vanilla recipe changes; this will look at another recipe's category when trying to change the category. For example, if a mod changes the category of speed modules from electronics, all of this mod's recipes that are intended for 'electronics' will inherit the category of speed modules. This is far from perfect, but again: EP is vanilla focused and mod support is not guaranteed.
  Bugfixes:
    - (Compat) Advanced science pack recipes should now properly reflect changes to the science pack icons made by other mods.
    - (Base,AoP) Ammunition is able to be crafted by the player again.
  Minor Features:
    - Advanced military science recipe now produces 4x the science (5 => 20) and takes 5x longer to craft (10s => 50s). This balances out the increased complexity and resource requirements by making the production rate 2x the vanilla recipe (0.2p/s => 0.4/ps; without productivity from the AoP armory or similar), as well as making the coal demand lower per science pack (before it was roughly 3x MORE coal per pack than vanilla).
  Info:
    - Inserters were previously not made outside of assembly machines (or AoP electromagnetic plant) due to my immersion philosophy: things with many small/moving parts (complex) should be made in assembly machines (precise assembly).
    - Exceptions being vanilla precedent or mod compatibility (ie if either vanilla or a compatible mod allows similar recipes in a given machine)
    - Other reasonable but against my immersion philosophy will also be available but off by default, check the mod config for any such implementations.
